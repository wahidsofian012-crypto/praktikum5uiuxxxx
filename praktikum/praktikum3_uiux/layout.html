Mengenal Pemrograman Web

Apa Itu HTML?

HTML digunakan untuk menyusun struktur halaman web, seperti judul, paragraf, gambar, dan tautan.

Apa Itu CSS?

CSS digunakan untuk mengatur warna, ukuran tulisan, jarak, dan tata letak halaman web.

Manfaat Belajar Web

Pemrograman web membantu kita membuat website untuk menyampaikan informasi dan mengembangkan aplikasi.
